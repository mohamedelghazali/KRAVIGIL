# Code of Conduct

## Our standard

Participation in KRAVIGIL discussions and contributions is expected to be professional, respectful, constructive, and security-minded.

Examples of behavior that supports a healthy community include:

- Using respectful language and welcoming good-faith questions.
- Critiquing ideas and code rather than attacking people.
- Accepting technical feedback and explaining disagreements with evidence.
- Respecting privacy and never publishing credentials, private reports, or customer data.
- Keeping security disclosures private until maintainers coordinate a safe disclosure.

Unacceptable behavior includes harassment, threats, discrimination, intimidation, personal attacks, doxxing, and deliberate publication of private or sensitive information.

## Maintainer responsibilities

Maintainers may edit or remove contributions, reject changes, or restrict participation when necessary to protect the project and its contributors. Decisions should be proportionate to the behavior and explained where practical.

## Reporting

For conduct concerns, contact the repository owner through the GitHub profile. For security vulnerabilities, follow [SECURITY.md](SECURITY.md) and do not use a public issue.
