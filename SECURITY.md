# Security Policy

## Supported versions

Only the current `main` branch is maintained for security fixes. No tagged release has been certified for production use yet.

## Reporting a vulnerability

Please do **not** open a public issue or pull request for an exploitable vulnerability.

1. Use GitHub's private vulnerability reporting / Security Advisories feature for this repository if it is enabled.
2. If private reporting is not available, contact the repository owner through the GitHub profile and request a private reporting channel before sharing technical details.
3. Include the affected commit or version, impacted component, reproduction steps, impact assessment, and any safe mitigation. Do not include real customer data, credentials, or production secrets.

Please allow maintainers a reasonable opportunity to investigate and prepare a fix before public disclosure. No response-time SLA is currently offered.

## Security scope

KRAVIGIL performs security scanning only against targets for which the operator has explicit authorization. Reports of vulnerabilities in KRAVIGIL itself should identify the affected component without testing or accessing third-party systems.
